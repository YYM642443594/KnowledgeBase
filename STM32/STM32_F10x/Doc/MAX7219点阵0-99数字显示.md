# MAX7219 点阵 0~99 数字显示功能

- 日期: 2026-10-28
- 范围: `bsp_ptj_module` (drv_max7219 + app_parse), 触发: 用户接线完成后提出 0~99 显示需求

## 实现方案

单块 8x8 点阵同显两位数字: 新增 **3x7 紧凑数字字模** (十位列0~2, 空列3, 个位列4~6, 列7留白, 行7恒空), 与现有 8x8 ASCII 字库并存互不影响。

| 层 | 内容 |
|----|------|
| DRV | `DrvMax7219ShowNum(num)` (0~99): 渲染进帧缓存 G_Ram 并整体刷新; 显示后自动停止走马灯滚动 |
| APP | `AT+DOTNUM=<0~99>`: 校验范围后调用; 未初始化回复 READY=0, 超界提示 0..99 |

## 使用

```
AT+DOTNUM=42      → 点阵同显 "42"
AT+DOTNUM=7       → 显示 " 7" (十位空)
AT+DOTSTR=HELLO   → 仍可走马灯(互斥: ShowNum 会停止滚动)
```
