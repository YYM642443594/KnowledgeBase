# 页面切换卡顿优化报告（P0 批次）

日期：2026-10-15 · 分支 develop · 工程仓库：gitee QT-Tools

## 问题现象

串口数据接入后，在不同页面间快速来回切换时出现明显卡顿。

## 根因分析（三源叠加 + Debug 放大）

1. **数据绑定转换风暴（主因）**：`DataPlotViewModel` 13 个数据列表属性（`QVariantList`）共用一个 `dataChanged` NOTIFY。波形页 4 张图 × 4 数组绑定 = 16 个 `property var` 绑定，每次 `dataChanged` 都全量重转换：1500 点 × 16 ≈ **24000 次 QVariant→JS 装箱转换/次**。触发源：10Hz 刷新定时器 + 每次进入数据页 `setViewActive(true)` 的立即 emit。绑定不受页面可见性门控，停在主图数据页时，隐藏的波形图绑定照常全量烧。
2. **调试页日志全量拷贝**：`mainVM.logs` 为 QVariantList（上限 5000 条 QVariantMap）。DebugPage `syncLogs() → rxLogs()` 每次全量读取并逐条深度转换为 JS 再过滤 RX。串口流下每 500ms `logsChanged` 一次；切回调试页 `onVisibleChanged` 再补一次突发。
3. **七页全量常驻（本批未改，P1 项）**：StackLayout 七页启动即全部实例化（仅波形页 Loader 延迟），每次切页全树可见性切换 + 布局重排，Quick3D 场景显隐还触发场景同步。
4. **放大器**：日常运行为 Debug 构建（MSVC /Od 无优化 + Qt Debug DLL）。

## 验证（2026-10-15）

- Debug 增量构建 `[100%]`；RelWithDebInfo 配置 + 全量构建 `[100%]`
- `--simulate 8s --size 1600x900 --grab` 截图精确像素计数（System.Drawing LockBits）：blue/red/green = **2992/3709/4245**（Debug）、**2993/3382/4359**（RelWithDebInfo）——三色曲线正常渲染，数据链路无回归
- `--page 0 --btscan 10`：蓝牙扫到 **7 台设备**；发现日志走 addLog→logTimer→logsChanged→syncLogs→`rxLogsSince` 全链路，运行窗口 **0 QML 错误**（无 TypeError/"is not a function"）
- perf_log.txt 在自测期间零写入（门控生效；最后一次写入为用户旧版会话 21:39:53）
- 编译坑记录：QVariant 无 `.value("key")` 成员（那是 QMap 接口），须 `.toMap().value()`，否则 C2672/C2440
