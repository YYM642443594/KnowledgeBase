# 蓝牙功能实现（扫描 + SPP 连接，2026-10-10）

需求：扫描周边蓝牙设备 + 连接其它蓝牙设备（串口数据链路）。

## 技术选型：为什么不用 Qt Bluetooth

| 项 | 结论 |
|---|---|
| 本机 Qt 6.11.1 MSVC 安装 | **未安装 Qt Bluetooth 模块**（lib/dll 均无） |
| 即便安装 | Qt 蓝牙在 Windows 上**不支持经典 SPP/RFCOMM 客户端连接**（WinRT 后端仅 LE），扫描可用但"连接串口设备"走不通 |
| 采用 | **Windows 原生双栈**：WinRT `DeviceWatcher`（扫描）+ Winsock `AF_BTH/BTHPROTO_RFCOMM`（连接） |

## 实现（bsp `Model/Bluetooth/BluetoothService`，pimpl 隔离）

- **扫描**：`DeviceInformation::CreateWatcher(aqs, props, DeviceInformationKind::AssociationEndpoint)`，
  AQS 同时匹配经典蓝牙协议 `{E0CBF06C-…}` 与 BLE `{BB7BB05E-…}`；属性取
  DeviceAddress/SignalStrength/IsPaired/IsConnected。AEP 依赖 Windows 后台持续发现，
  周边设备几秒内陆续上报。25s 自动停止；结果按 RSSI 降序限 64 条，200ms 合批。
- **跨线程纪律**：WinRT 回调在线程池触发，回调内**只提取纯值**（QString/qint64/bool）
  再 `QMetaObject::invokeMethod(Qt::QueuedConnection)` 投递 UI——绝不跨线程持有 WinRT 投影对象。
- **连接**：worker 线程非阻塞 `::connect` + `select` 8s 超时 → SPP（`SerialPortServiceClass_UUID`
  0x1101，**无需预先配对**，ESP32/HC-05 类 SPP 服务端直连）。成功后回阻塞模式 recv 循环，
  数据经队列信号回 UI；断开 = `closesocket` 即刻解除阻塞 recv。发送 `SO_SNDTIMEO=3s` 防卡 UI。
- **数据链路**：CommViewModel 把 `BluetoothService::dataReceived` 接到与串口**同一** DataParser
  管线（协议帧解析/波形/日志/录制全复用）；`connectBluetooth(address)` 自动切换 CommType。

## UI（BluetoothPanel 侧栏，SidePanel 注入 mainVM）

扫描/停止/清空按钮、设备列表（名称/地址/RSSI/已配对徽标，单击选中双击直连）、
手动地址输入连接/断开、适配器与连接状态行。MainViewModel 门面转发
`btDevices/btDiscovering/btAvailable/startBtDiscovery/stopBtDiscovery/clearBtDevices/connectBluetooth/disconnectBluetooth`。

## 踩坑记录（编译/链接）

1. cppwinrt 头要求 **`/permissive-`**（仅对 BluetoothService.cpp 设置 source 属性，避免影响全局）。
2. MSVC 14.51 下 winrt 头拉 `<experimental/coroutine>` → 硬错误，需
   `_SILENCE_EXPERIMENTAL_COROUTINE_DEPRECATION_WARNINGS`。
3. winrt 头必须在 windows.h **之前**包含（rpcndr 的 `interface` 宏冲突）；winsock2.h 在 windows.h 之前。
4. Impl（QObject 派生类的嵌套）里裸调 `connect(...)` 被 **QObject::connect 名字遮蔽** → 必须 `::connect`。
5. `CreateWatcher` 是 **DeviceInformation 的静态工厂**，不是 DeviceWatcher 成员。
6. 链接缺 `runtimeobject.lib` → `WINRT_IMPL_RoGetActivationFactory/RoOriginateLanguageException` 未解析。
7. `BluetoothFindFirstRadio`（BluetoothApis.lib）查适配器可用性。

## 验证

- `CommTools.exe --btscan 20`（main.cpp 自测钩子，1.5s 起扫、N 秒停止并把设备写入 debug.log）：
  本机（MediaTek 适配器）实测 **20s 扫到 12 台**——已配对 S100 / XFW-BT（paired=true，AEP 缓存项 RSSI=0）、
  美的电器 ×2、多台 BLE（无广播名显示地址），按信号强度降序（-45 → -88 dBm）。
- 启动 0 QML 错误；SPP 连接为交互功能需实机连 ESP32/HC-05 类设备复测
  （扫描/收发管线与串口共用，风险集中在 RFCOMM 直连本身）。
