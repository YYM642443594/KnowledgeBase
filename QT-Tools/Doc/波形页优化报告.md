# 实时波形页优化报告（2026-10-10）

用户反馈两个问题：①软件运行一段时间后卡顿；②波形页 Y 轴量程固定，看不出实时变化。
本文档记录根因、修复方案与实测证据。gitee 提交：波形页重构（develop，2026-10-10）。

## 一、卡顿根因（三个，全部修复）

### 1. rebuildNeeded 全清重建尖峰（主因）
- 后端 `DataPlotViewModel` 存储裁剪到 1500 点后发 `rebuildNeeded`，
  旧 QML 收到后 `resetChart()` 清空全部 series，下一 tick 一次性重建
  4 图 × 3 系 × 1500 点 = **1.8 万点** → 主线程阻塞尖峰。
- 修复：`updateChart()` 改为**整窗重绘**（同一 JS 块内 `clear()+append(批量)`，
  场景图只同步一次）。裁剪对组件透明，`onRebuildNeeded` 监听整个删除。

### 2. remove(0,n) 前删 O(n)
- 旧代码每 tick 追加新点后从 series 头部删除旧点（O(n) 搬移+整缓冲重传）。
- 修复：整窗重绘天然消除索引/前删状态。

### 3. DebugPage 隐藏页日志全量过滤（设备场景）
- DebugPage 位于 StackLayout（非 Loader），`onLogsChanged → syncLogs → rxLogs()`
  对 `mainVM.logs`（QVariantMap 列表）做 **O(上限) 全量过滤+JS 重建**，无可见性守卫。
  设备 50Hz 推流时即使停在波形页也被逐帧唤醒——"运行一段时间后卡顿"的来源
  （日志滚动窗口填满后成本恒定在满量）。
- 修复：`if (!root.visible) { logDirty = true; return }` + `onVisibleChanged` 补同步
  （seq 增量机制天然支持，切回页面看到离开期间的全部日志，XCOM 行为不变）。

## 二、Y 轴固定 → 自适应

- 旧：固定量程（角速度 ±500°/s、静态噪声 ±1°/s 仅占画布 0.2% → 视觉直线）。
- 新：`autoScaleY`（默认开）——可见窗口数据 min/max + 15% 边距，吸附 **1-2-5 nice 刻度**
  （约 4 主刻度），迟滞策略：数据越界立即扩、范围大于目标 2.5 倍才缩，避免轴抖动。
- 图例带**实时数值**（彩色等宽字体），网格线可见，线宽 2px，Y 轴标签精度随量程自适应
  （≥200 → %.0f、≥20 → %.1f、否则 %.2f）。一键"自适应Y:开/关"切回固定量程。
- 自适应数学已用运行时插桩逐字验证：数据 [-3.75,2.98]→轴[-5,5]、[-4.12,9.11]→[-10,15]、
  [-75.0,49.6]→[-100,100]。
- X 窗口自适应：`min(windowSec=30s, 数据跨度)`，启动初期自动放大细节。

## 三、顺带修复：模拟数据 float 精度 bug

`onSimulateTimeout` 用 `float t = timestamp/1000.0f`（epoch 秒 ≈1.79e9，float 步长 128s）
→ 所有模拟值恒定、曲线为水平直线。改为相对时间基准 `m_simStartTimestamp`；
yaw 由无界斜坡 `t*10` 改为 `fmod(t*20, 360)`。

## 八、用户反馈迭代三（同日 12:41）：X/Y 轴刻度字号自适应

诉求：全部展开时轴文字部分看不清。排查发现两层根因：

1. **QtGraphs 2D 轴无 labelFont 属性**（QAbstractAxis 只有 labelDelegate: Component）。
   刻度文字样式须经 `labelDelegate: Text { color; font.pixelSize }` 设置；
   官方文档：delegate 应为 Text 或含 `property string text`（框架对其赋值）。
2. **GraphsView 刻度拥挤时会整行隐藏**：窗口 1200×800 四图全展开（每图 ~150px）时
   默认固定字号刻度全部被隐藏（debug.log 证实 delegate 实例 vis=false）——这才是
   “看不清”的根源；1920×1040 下同密度刻度正常渲染。

修复（gitee 1756dd0）：

- `axisFontPx = clamp(round(graphsView.height / 18), 9, 16)`，X/Y 轴共用；
  全部展开→9px 保刻度不被隐藏；单图放大→16px。深灰 #475569 提升白底对比度。
- main.cpp 自测钩子新增 `--size WxH`（如 1920x1040）验证不同布局。
- 验证：1920×1040 抓屏 Y 标签带 18-21 物理 px（≈13 逻辑 px，与公式吻合）、
  1200×800 下更小更少（GraphsView 拥挤管理），两尺寸 0 QML 错误。

踩坑记录：

- delegate 在窗口构建期创建（此时 graphsView.height=0，字号绑定初始为下限），
  字号须用绑定而非创建期快照，布局完成后自动更新；框架后续夏用实例并赋 text
  （630 次 text 更新 vs 96 次创建）。
- 像素验证脚本必须按 DPR 换算物理坐标（本机 grab：1920×1040→2884×1760=DPR1.5；
  1200×800→2400×1600=DPR2），否则窗口错位全部扫空。
- GraphsView 红色曲线(#EF4444)会命中“红色文字”像素判定（R>170,G<90,B<90），
  探针配色需避开系列色（纯蓝#0000FF 可与系列蓝#3B82F6 区分：G 通道 0 vs 130）。

## 九、用户反馈迭代四（同日 13:25）：Hex页接收区显示不全 + 波形页自选报文源

### 诉求①：HexCommands 页接收区数据显示不全

- **根因**：原代码把 ScrollBar 直接挂在 TextArea 上，但 TextArea 并非 Flickable
  （无 contentY/contentHeight）——滚动条是死的，超出视口的长文本被 clip 直接裁掉，
  无法滚动查看。（验证：给 TextArea 写 onContentYChanged 直接报
  `Cannot assign to non-existent property`，编译期坐实。）
- **C++ 侧叠加因素**：推送模式下 `m_receivedDataText = pendingDataText` 整帧替换
  （50Hz 只显示最新一帧），多行帧文本在替换间隙根本读不完。
- **修复（gitee 87e9f74）**：
  1. Flickable 包裹 + `TextArea.flickable: TextArea{...}` 附加属性（Qt 文档标准结构）
     ——滚动真正生效，ScrollBar 挂在 Flickable 上；
  2. 自动跟随：新内容到达时滚到底部（Qt.callLater 等布局完成），
     用户上翻阅读时暂停跟随（onContentYChanged 更新 followTail）；
  3. “暂停显示”冻结按钮：定格当前文本便于读完整帧，数据仍在后台接收解析。

### 诉求②：波形页直接选择报文源（不依赖 Hex 页配置）

- 协议 3.2.3.7：推送报文ID控制 = 0x00 0x11 帧，DATA1=CMD、DATA2=ID、DATA3=开关；
  可控报文 0x0001/0x0002/0x0010/0x0013。
- 新增 `Q_INVOKABLE sendPushIdControl(msgIdHex, on)`：不读 Hex 页的
  m_selectedData1/Data2/Op，独立构帧（OP 固定 0x01 = 配置到 RAM，运行时生效不保存）。
- MainView 波形页头部新增：数据源 ComboBox（0x0010/0x0001/0x0013）+ 停止推送按钮。
  **切换时先关其它传感器源再开目标源**——多源同时推送会交错 addDataPoint 致波形混叠；
  0x0002 设备状态未列入（图表不消费）。
- 注意：sendPushIdControl 与 sendCommand 一样会清空接收区等待应答，
  Hex 页暂停显示的冻结快照不受影响。

## 十、主图数据页三格式保存 / 波形页推送开关 / 串口记忆（2026-10-10）

### 诉求①：主图数据页数据记录与 CSV/TXT/MAT 保存

- 为什么加录制器：图表缓冲是 1500 点滚动窗口（超限裁剪），“保存所有数据”必须有
  完整历史缓冲。DataPlotViewModel 新增 RecRow 全历史录制（startRecording/
  stopRecording/clearRecording/saveRecording + recording/recordedRows 属性），
  在 onUpdateTimeout 的 m_dataMutex 锁内批量追加；扩展字段（温度/频率/|A|/|W|/
  四元数/PPS/UserA/电量/设备时间）用同 tick 已提交的 m_latest* 快照与 12 通道配对；
  200 万行上限自动停（内存保护）。
- 27 列：Time_s(相对首录行)+AX..MZ+AccNorm/GyroNorm+Q1~Q4+Temp(C)/Freq(Hz)/
  PpsLock/PpsMode/UserA/Battery(%)/TsUs(us)/DateTime。CSV 逗号、TXT 制表符；
  值用 QString::number(v,'g',10)（float 与 ms 时间戳无损），QTextStream
  setLocale(QLocale::c()) 锁定小数点为 '.'。
- MAT 手写 MATLAB Level 5（v6 兼容）小端，零第三方依赖：
  - 128B 头 = 116 描述 + 8 保留 + uint16 版本 0x0100 + "IM"（小端标志）；
  - miMATRIX 四子元素：array flags(miUINT32: class+0) / dims(miINT32) / name(miINT8) /
    data(miDOUBLE)，每子元素 8 字节对齐填充；
  - 26 个数值字段各 n×1 double 列向量（MATLAB 变量名：Time_s、AX..MZ、AccNorm、
    GyroNorm、Q1..Q4、Temp_C、Freq_Hz、PpsLock、PpsMode、UserA、Battery、TsUs）；
  - DateTime 为 n×L 列主序 UTF-16 char 矩阵（空串补空格，MATLAB cellstr() 取每行），
    元素(i,j)=codes[i+j*n]；
  - double 经 memcpy 写出，依赖宿主小端（x86/ARM64 Windows 均满足）。
- 原生保存对话框：部署目录缺 QuickDialogs2 插件，QML FileDialog 会加载失败；
  AppSettings.selectSaveFile（原生 QFileDialog，返回 {path, filter}），
  QML 侧按过滤器自动补扩展名。
- 验证：--autorecord <dir> 钩子（0.5s 起录、seconds-1 停录同时落盘三格式）；
  Python 规范回读脚本 verify_mat.py（独立解析器）与 CSV 列交叉比对：
  27 变量/670 行，AX 与 Time_s 与 CSV 完全一致，DateTime 矩阵 n/L/维度正确。
  1 对同毫秒相邻行 = 模拟定时器抖动（真实数据特性，录制器不丢不重排）。
- 踩坑：build 目录未部署 Qt DLL，独立运行 exe 需先前置 Qt/MinGW bin 到 PATH，
  否则 0xC0000135（DLL not found）秒退且不写任何日志。

## 十二、波形数据不正常根因修复（2026-10-10）

### 现象

- 实机连接后“可以看到数据，但显示的波形数据不正常”（Hex/调试页有数据，波形冻结/空白或异常）。

### 根因①（主）：数据入口被 Hex 页选中命令过滤

- 五个数据入口 onNewSensorData(0x0001)/onNewSensorDataPacket(0x0010)/onNewStatusPacket(0x0002)/
  onNewSensorData0013(0x0013)/onNewAllData 全部以 isCommandSelected(cmd,id) 起手——
  要求 Hex 页当前选中命令与到达报文一致才送入图表。
- 波形页“数据源”下拉（sendPushIdControl）只发 0x00 0x11 帧切换设备推送，不更新 Hex 页选中项：
  Hex 页选错/未选（selectedCommand 为空）时数据全部被丢弃 → 波形冻结，数据只在 Hex/调试页可见。
- 修复：五处解除过滤，到达即绘图。波形页下拉独占切换（选中即关其它源）天然防混叠；
  Hex 页选中项回归“编辑/测试命令”本职，不再约束绘图。

### 根因②：0x0001 设备微秒时间戳当毫秒用

- onNewSensorData 将 data.Timestamp（协议 3.1.3.4，单位 us，quint64）直接作为图表时间戳，
  而其它路径均用 PC 毫秒（QDateTime::currentMSecsSinceEpoch）——X 轴时间快 1000 倍。
- 修复：图表时间戳统一 PC 毫秒；设备 us 时间戳保留在扩展信息 tsUs（主图页列/录制文件 TsUs 列）。

### 排查方法记录

- 构建目录 debug.log 无实机会话 → 用户运行的是部署版 exe（各自目录有自己的日志），
  build 目录日志只能看到自测记录。
- 从“数据可见但波形不动”定位到收包与绘图之间必有过滤层，顺藤摸瓜 grep addDataPoint 上游。

- 主仓 `72cdc8c`（移除停止推送按钮）、`8a7f9da`（本节两根因修复）；bsp 无改动；

- **Shift+滚轮**：以光标为中心缩放 Y 轴（每档 1.25 倍；屏幕 y 向下、值域向上，

  （angleDelta.y=0 时取 angleDelta.x 定方向）。
- **Ctrl+滚轮**：X+Y 双轴同缩；无修饰滚轮仍为纯 X 缩放（第十一节行为不变）。
- **右键拖拽**：Y 平移（抓取点保持在光标下，拖下=看更大值）；左键拖拽仍为 X 平移。
- **Y 手动模式**：`applyYRange` 统一限幅（跨度 1e-6～1e9 绝对限幅，各通道量纲差异大）
  后置 `yManual=true`；`renderWindow` 手动分支直接套用 `yViewMin/yViewMax`，
  与实时跟随解耦——实时滚动中也可锁定量程（超出范围数据由 GraphsView 裁剪）。
- **恢复自适应**：双击/「回到实时」恢复跟随且 Y 回自适应；手动期间头部出现
  「Y自适应」按钮一键恢复（不退出历史查看模式）；Clear 也复位 yManual。
- 卡片头部新增灰色 9px 操作提示（滚轮:X缩放 Shift+滚轮:Y缩放 Ctrl+滚轮:双轴
  左/右键拖拽:X/Y平移 双击:复原），原占位 Item 换为右对齐 elide 文本。
