## 跨平台知识链（串口丢字节，全平台通用）

```text
[GD32F303] 0x091时间戳抖动修复报告             [GD32F303] 串口丢字节修复报告                [GD32F103] 921600波特率串口丢字节排查报告
选定"SysTick ISR 时基差值累加"方案 ──回归──▶ dwt.h 64 位软件除法拖长最高优先级中断 ──修复──▶ 32 位硬件除法
                                                                                        ▲
                                                            103 平台同款根因，排查报告参照 351（GD32F303 工程）修复经验闭环
```

核心纪律（三份报告共同沉淀，写中断相关代码前先读）：

1. 优先级高于串口 RX 的中断里，禁用 64 位乘除、`printf`、`double`（软除法/软浮点数百周期起）
2. 任何可能阻塞 RX 的执行路径，总时长必须显著小于最高波特率下 1 字节时间（921600→10.86µs）
3. 串口接收队列每拍排空；ISR 队列满时丢弃新字节，禁止满态重置索引
4. 度量 RX 丢失率前先确认 TX 单一路径，否则回显法结果不可信

## 归档规则

1. 报告按**所属工程（MCU 平台）**归档入对应目录；同平台新产品的报告同样入该目录，产品号记录在报告正文与目录 Readme
2. 跨平台通用经验不单独建目录，沉淀到本索引「跨平台知识链」区并链接原始报告
3. 报告内引用其它报告一律用相对链接（如 `../GD32F303/xxx.md`），不写旧工程目录名
