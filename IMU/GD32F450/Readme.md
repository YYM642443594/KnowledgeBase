# GD32F450 平台知识库

> 2026-11-28 新建：501 项目（GD32F450VGH6）并入知识库。
> 固件工程 GD32F4xxMCU（分支 `feature/501Project`，编译目标 GD32F450VGH6，宏 BSP_501_PROJECT /
> HARDWARE_501_D00）+ 内嵌 BSP_IMU 子仓库（分支 `develop`）。传感器 IIM-42652（ICM42688 兼容，
> 片上温度）+ BMM350 磁力计，扩展版 NavFusion 算法链（506/507 同款）。与 [GD32F470/](../GD32F470/)

> 框架同源，阅读时注意区分。

## Flash 分区速查（GD32F450VGH6, 1MB）

| 地址 | 区域 |
|------|------|
| 0x08000000~0x0801FFFF | Loader/APP 固件区（升级框架与 507 同源，上界 0x08020000） |
| 0x08020000 / 0x08040000 | 产品信息页 A/B（扇区5/6） |
| 0x08060000 | 标定参数区（扇区7，128KB 独立扇区，`IMU_501_CALIBRATION_PARAM_ADDR`；整扇区擦写约 1~2s 阻塞） |
| 0x08080000~0x080FFFFF | 预留 |

## 传感器与单位域

| 项 | 说明 |
|----|------|
| 六轴 | IIM-42652（`drv_icm42688`）：加速度已乘 CONSTANT_GRAVITY → 内部链 **m/s²**，与 303/333/335/506 同域，标定流无需单位换算 |
| 磁力计 | BMM350，LM 椭球拟合校准（量产 303 同款，样本缓冲库内 malloc） |
| 量程 | 默认最大 16g / 2000dps，支持 HEX/AT/CAN/PC 四通道实时切档 |

## CAN 能力（2026-11-28 审计结论）

与 506 同级、平台内覆盖最全：19 项接收指令表全生效（0x100~0x118，无产品宏守卫）、完整/精简数据流
推送（`DrvCAN0Send` 直发，区别于 351 队列模式）、0x119 磁/0x120 压推送（501 无气压计，0x120 恒 0）、
0x117 磁校准进度、0x111 零偏 CAN 回复。真 335（GD32F103）产线**不使用 CAN**（CAN 代码为死代码），
标定指令两侧均走 UART/HEX 表，501 与 335 行为一致。
