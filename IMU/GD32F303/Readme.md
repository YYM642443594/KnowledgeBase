# GD32F303 平台（工程 IMU_303_351 / GD32F303MCU）

## 工程与产品映射

| 固件工程 | 仓库/分支 | 硬件号 | MCU | 传感器 | 服务产品 | 特性差异 |
|----------|-----------|--------|-----|--------|----------|----------|
| IMU_303_351 | IMU_303_351 工程 | C00 | GD32F303CB（HD，128KB/32KB）@120MHz | 内置六轴（+PPS 授时） | 351 | PPS 完整功能 |
| GD32F303MCU | BSP_IMU 子仓 `develop` + 主仓 `feature/506Custom` | B06 | GD32F303CGT6（XD，1MB/96KB）@120MHz | **SCH16T-K01 六轴 IMU（SPI）+ RM3100 外置磁力计（SPI0，CMM 600Hz）** | 506 | 无 PPS 硬件；九轴自研融合（六轴 + 外置磁）；量程配置暂缓；LabView 50Hz 调试推送暂缓 |

> 506 功能对齐 351：同一 BSP_IMU 子仓、同一套 AT/HEX/CAN 指令表，产品差异由硬件特性表 `BspDevFeature_S`（bsp_feature.c）与 `BSP_506_PROJECT` 宏隔离；算法模式 0x06 位图 B06 = 6 轴自研 + 9 轴自研。
> 时间体系：506 无 PPS 脉冲源，日历 = 上位机设置一次 + 内部时基（SysTick 1kHz + DWT 增量）走时；351 可由 PPS/GPS 校准。
