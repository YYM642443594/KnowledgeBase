# 小区自动售水机通信协议

[TOC]



------

# 1 文档概述

​	本文档主要描述小区自动售水机的通信协议格式，用于集成和配置小区自动售水机。



------

# 2 协议介绍

​	小区自动售水机私有协议设计用于和平台之间进行通信，该协议具备一下特性：

1. 紧凑：使用`8bit`二进制数据
2. 数据校验：使用低开销的校验算法
3. 交互方式：协议采用一应一答的交互方式



------

# 2.1 数据交互协议

### 2.1.1 协议帧格式

​	小区自动输售水机数据输出采用固定的格式，帧结构包含*部分：帧头、`CRC8`校验码、命令集`CMD`、命令`ID`、长度、数据域、`CRC16`校验码，如下所示：

| 帧头   | `CRC8` | 命令集`CMD` | 命令ID | 数据域         | `CRC16` |
| ------ | ------ | ----------- | ------ | -------------- | ------- |
| `0xA2` |        | 0~255       | 0~255  | 数据包有效数据 | 校验码  |
| 1字节  | 2字节  | 1字节       | 1字节  | 0~255 字节     | 1字节   |

​	数据输出协议帧结构定义如下：

```c
/* 数据输出协议帧报文头 */
typedef __packed struct
{
    unsigned char Head1; /* 帧头 0xA2 */
    unsigned short CRC8; /* 帧头 0x55 */
    unsigned char CMD;   /* 命令集CMD */
    unsigned char ID;    /* 命令ID */
} BspOutDataHeader_S, *pBspOutDataHeader_S;

/* 数据输出数据包结构 */
typedef __packed struct
{
    BspOutDataHeader_S BspOutDataHeader;
    DATA, /* 输出的数据结构体，详情参考2.1.x章节内容 */
    unsigned short CRC16;
}SerialOutData_S,*pSerialOutData_S
```

### 2.1.3  应答方式

​	如果设备收到服务器发送过来的数据，在处理完成后会按照收到的命令集`CMD`以及命令`ID`进行回复，回复的命令集`CMD`以及命令`ID`就是收到的，并附带一个字节的空数据。

/**
 * @brief CRC8计算函数
 *
 * @param buf 数据缓冲区指针
 * @param len 数据长度
 * @return * unsigned char CRC8值
 */
unsigned char BspCRC8ValueCal(unsigned char *buf, unsigned short int len)
{
    unsigned char crc8_init = 0x77;
    unsigned char index_cnt = 0;

    while (len--)
    {
        index_cnt = crc8_init ^ (*buf++);
        crc8_init = crc8_tab[index_cnt];
    }

    return crc8_init;
}

/**
 * @brief CRC16计算函数
 *
 * @param buf 数据缓冲区指针
 * @param n 数据长度
 * @return unsigned short int CRC16值
 */
unsigned short int BspCRC16ValueCal(unsigned char *buf, unsigned short int n)
{
    unsigned short int i = 0;
    unsigned char j = 0;
    unsigned short int crc16_init = 0x3692; 

    for (i = 0; i < n; i++)
    {
        crc16_init = crc16_init ^ buf[i];

        for (j = 0; j < 8; j++)
        {
            if (crc16_init & 1)
            {
                crc16_init = crc16_init >> 1;
                crc16_init = crc16_init ^ 0x8408;
            }
            else
            {
                crc16_init = crc16_init >> 1;
            }
        }
    }
    return crc16_init;
}
