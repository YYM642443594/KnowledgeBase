# 知识库网页视觉设计规范（M1 基线）

> 记录 `kb-viewer-template.html` M1 视觉基础精修的关键设计取值与实现要点，作为后续 M2（首页与图标升级）、M3（功能增强）的样式基线。完整改动以模板文件为准，本文记录「为什么是这个值」与「改动的坑」。

## 结论（M1 改了什么）

- **层级**：三级背景拉开明度差（旧值 `#0f1117 / #161a23 / #1d222e` 相差过小），边框拆两级，卡片加静置/悬浮阴影，滚动条与焦点样式统一；
- **排版**：正文 920→820px（15px 字号约 53 字/行），行高 1.65→1.75，标题节奏放缓；
- **联动**：侧栏分区色从「仅图标背景」扩展为当前分区高亮（分区色竖条 + 浅色底）+ 当前文档项 accent 竖条；
- **动效**：全部过渡时长收敛为两个令牌，模板内不再出现字面时长。

## 设计令牌（:root）

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--bg` | `#0c0e14` | 页面最底层 |
| `--bg2` | `#151a26` | 侧栏、代码块、卡片底 |
| `--bg3` | `#1d2536` | 输入框、表头、浮起面 |
| `--bg-hover` | `#26304a` | 列表项 hover |
| `--border` | `#273044` | 结构性边框：分栏、分割线 |
| `--border-soft` | `#1e2536` | 次级边框：表格线、引用条 |
| `--t-fast` | `.15s ease` | hover / 箭头旋转 / opacity 等反馈 |
| `--t-med` | `.25s cubic-bezier(.4,0,.2,1)` | 移动端侧栏、目录显隐等位移/滑入 |

排版基线：`#article` / `#welcome` max-width 820px；body 行高 1.75；字体栈在 PingFang SC 后插入 HarmonyOS Sans SC；标题节奏 h1 1.7rem（下距 10px / 分隔 padding 14px）、h2 1.28rem（上距 40px）、h3 1.08rem（上距 30px）、h4 上距 22px；正文段落上下距 12px。

侧栏分区色仍由 `kb_build_viewer.py` 的 `SECTIONS` 定义（esp `#4f8cff`、imu `#3fb27f` 等），M1 起以 CSS 变量方式注入使用。

## 侧栏分区色联动的实现要点

1. `buildNav()` 给每个 `.nav-sec` 注入 `--sec`（分区色）与 `--sec-a12`（同色 hex + `1f` 后缀 ≈ 12% 透明度），并在节点上写 `data-sec`；
2. `setActiveNav()` 依据 `docByHash(state.current)` 给当前分区切 `.cur` 类：分区头浅色底 + 2px 分区色竖条；同时自动展开该分区（写入 `navOpen`，搜索重建侧栏后仍保持）；
3. **坑**：页面 boot 时 `renderDoc()`（内含 `setActiveNav`）先于 `buildNav()` 执行，此刻侧栏还是空 DOM → 直链打开文档时高亮不生效。修复方式是 `buildNav()` 末尾补偿调用一次 `setActiveNav()`；后续若调整 boot 顺序，注意保留该补偿。

## 体积与构建

- M1 模板净增约 2.1KB（纯 CSS + 约 15 行 JS），生成物增量中 viewer 自身部分远小于 5KB 门槛；
- **坑**：`python kb_build_viewer.py` 直接运行会 `KeyError: 0`——其 `__main__` 把整个 kb-commits.json（`{_meta, commits}` 字典）传给 `build()`，而 `build()` 期望 commits 列表；流水线实际走 `kb-sync.py` 的 `build_once()`：`fetch_commits()`（git log 过滤 viewer 自动提交取前 30 条）→ 设 `HEAD_OVERRIDE` → 重写 kb-commits.json → `build(commits)`。本地手动重建需按此顺序调用；
- 2026-11-13 重建时生成物 +29KB，其中模板改动仅 +2.1KB，其余为陈旧生成物补齐 commit 2bb6216 新增的两个 STM32 文档内容（文档总数 54→56），属一次性数据追赶。

## 本地核验注意（Windows）

- Edge headless（`--headless=new --screenshot`）的 `--window-size` 宽度小于约 500px 时会被 Windows 窗口最小宽钳制，截图画布与实际视口不一致 → 窄屏（375px）核验需用「外壳页 + 固定宽 iframe」方式，媒体查询按 iframe 宽度生效，才是真实移动端布局；
- `--screenshot` 传相对路径会静默失败，务必用绝对路径；Edge 启动器进程先退出、文件稍后落地，脚本需轮询等待；
- 文档页 URL 用仓库相对路径作 hash（如 `知识库.html#ESP/ESP-8266/Readme.md`，非 ASCII 需百分号编码）。
