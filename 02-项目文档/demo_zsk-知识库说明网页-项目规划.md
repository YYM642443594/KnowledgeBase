# demo_zsk-知识库说明网页-项目规划

## 概述

本文档是 demo_zsk 项目（知识库说明网页）的规划文档，定义项目背景、目标、开发思路、项目结构与开发计划，并约定开发过程中向知识库沉淀内容的流程。适用于本项目全程的开发与维护参考。

## 1. 项目背景

个人知识库（Git 仓库 KnowledgeBase）已具备完整的目录体系与规范文档，但缺少一个直观的总览入口。本项目开发一个**简单的知识库说明网页**，用于：

1. 展示知识库的定位、目录结构与使用方式；
2. 作为知识库的可视化导航入口；
3. 通过本项目自身的开发过程，验证「开发 → 沉淀」的知识库工作闭环。

## 2. 项目目标

### 目标 1：知识库沉淀（贯穿开发全程）

开发过程中，将开发经验和技术栈内容按照知识库**既有规范**沉淀到知识库仓库。规范依据（单一来源，不另立标准）：

- `README.md` — 人类向完整规范（分类、命名、编写、维护）；
- `AGENTS.md` — AI Agent 工作规范（目录选择、索引登记、硬性规则、会话工作流）；
- `00-索引/模板-知识文档.md` — 唯一文档模板（YAML front-matter：title / created / updated / tags / source）。

**内容 → 目录映射**：

| 本次工作产出 | 沉淀目录 |
|------|------|
| 技术栈卡片（HTML / CSS / JS 用法） | `01-技术笔记/`（本项目为前端方向 → `01-技术笔记/前端/`） |
| 项目设计、方案、复盘 | `02-项目文档/` |
| 踩坑与排障 | `03-问题排查/`（现象 → 原因 → 解决方案 → 预防措施） |
| 工具配置、使用技巧 | `04-工具使用/` |

**沉淀流程（每篇文档必须完整执行）**：复制模板 → 填写 front-matter → 规范命名（语义化中文，不含空格与特殊字符）→ 在 `00-索引/索引.md` 登记并登记新标签 → `git commit`（前缀 `新增：` / `更新：`）并 `git push origin main`。

**会话闭环**：每次开发会话开始时 `git pull --rebase origin main` 并读索引；结束时判定沉淀内容、落盘、登记索引并推送。push 失败时保留本地提交并如实说明。

**验收标准**：知识库中有本项目沉淀条目，全部符合模板格式、命名规范且已登记索引。

### 目标 2：交付知识库说明网页

- 零依赖纯静态单页，双击 `index.html` 即可使用，无需构建与依赖安装；
- 展示内容：知识库简介、目录结构树、分类卡片、文档索引、本地搜索。

## 3. 开发思路

- **零依赖静态页**：纯 HTML5 + CSS3 + 原生 ES5+，不用框架、不用构建工具；
- **file:// 约束优先**：目标场景是「双击打开」，因此放弃 ES Modules（file:// 下受 CORS 限制无法跨脚本 import），采用普通脚本 + 全局数据对象（`data.js` 挂载 `KB_DATA`）的组织方式；
- **数据驱动**：知识库结构、分类、文档条目全部独立在 `data.js`，`main.js` 只负责渲染。知识库内容更新时只改数据，不改页面逻辑；
- **网页即活文档**：页面展示的目录结构、分类说明与知识库真实结构保持一致，数据来源对齐 `README.md` 的分类说明表。

### 技术选型

| 层面 | 选型 | 理由 |
|------|------|------|
| 结构 | HTML5 语义化标签（header/main/section/footer/nav 语义） | 无依赖、可访问性好 |
| 样式 | 原生 CSS3（Grid `auto-fit` + 自定义属性主题） | 免媒体查询实现响应式卡片，主题色一处配置 |
| 逻辑 | 原生 JavaScript（IIFE 封装 + 事件委托） | 简单场景不引入框架 |
| 构建 | 无 | 零构建，file:// 直接运行 |

### 页面功能

| 模块 | 说明 |
|------|------|
| 头部 | 标题、简介、分类数与文档数统计 |
| 本地搜索 | 按标题/说明/标签即时过滤，`/` 快捷键聚焦，空态提示 |
| 目录结构 | 树形展示知识库真实目录（数据来自 data.js） |
| 分类卡片 | Grid 响应式卡片：图标、说明、文档数，搜索时无匹配分类置灰 |
| 文档索引 | 按分类分组的文档列表（标题、路径、说明、标签） |

## 4. 项目结构

```
demo_zsk/
├── docs/
│   └── 项目规划.md            # 本文档（同步沉淀至知识库 02-项目文档/）
├── index.html                 # 页面入口
├── css/
│   └── style.css              # 全部样式（主题变量 + 组件样式）
└── js/
    ├── data.js                # 知识库结构数据（全局 KB_DATA，与渲染分离）
    └── main.js                # 渲染与交互逻辑（不含内容数据）
```

## 7. 风险与后续计划

| 项 | 说明 | 处理 |
|----|------|------|
| 数据与知识库真实状态同步 | 网页 data.js 为手工维护，知识库更新后需手动修改 | 后续可写脚本从 `00-索引/索引.md` 自动生成 data.js |
| 需求范围膨胀 | 「简单」目标易被突破 | 功能以本文档 3 节表格为限，新增需求先更新本文档 |
| 空分类展示 | 多数分类暂无文档 | 卡片显示 0 篇并置灰样式区分，随知识库成长自然填充 |
